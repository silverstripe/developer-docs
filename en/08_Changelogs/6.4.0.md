## Features and enhancements

### New module to display user documentation {#userdocs-admin}

We have created a new module ([`silverstripe/userdocs-admin`](https://www.github.com/silverstripe/silverstripe-userdocs-admin)) that adds a new CMS section to display documentation aimed towards users of the CMS.

This module will be installed by default for any new project using [`silverstripe/installer`](https://www.github.com/silverstripe/silverstripe-installer), and existing projects which have [`silverstripe/recipe-cms`](https://www.github.com/silverstripe/recipe-cms) as a dependency. If you want to install this module in an existing project that doesn't use that recipe, you will need to install it to that project yourself.

By default this module will automatically include documentation for the [commercially supported modules](/project_governance/supported_modules/). You can also add documentation for your own modules and project-specific functionality, as well as override and localise documentation. See [Userdocs admin developer docs](/optional_features/userdocs-admin/) for details.

### Other new features and enhancements {#other-new}

- [`InterventionBackend::getImageResource()`](api:SilverStripe\Assets\InterventionBackend::getImageResource()) no longer creates a temporary file before handing assets to Intervention Image. Instead it leverages functionality from Intervention Image 3 that reads EXIF data directly from the stream.

## API changes

### Deprecated API

The following API has been deprecated in this release, and will be removed or replaced in a future major release.

It's best practice to avoid using deprecated code where possible, but sometimes it's unavoidable. This API will all continue to be available at least until the next major release.

- The [`Director::is_cli()`](api:SilverStripe\Control\Director::is_cli()) method has been deprecated. Use [`Environment::isCli()`](api:SilverStripe\Core\Environment::isCli()) instead.
- The [`InterventionBackend::getTempPath()`](api:SilverStripe\Assets\InterventionBackend::getTempPath()) method has been deprecated and will be removed without a replacement.
- The [`InterventionBackend::setTempPath()`](api:SilverStripe\Assets\InterventionBackend::setTempPath()) method has been deprecated and will be removed without a replacement.
- The [`InterventionBackend.local_temp_path`](api:SilverStripe\Assets\InterventionBackend->local_temp_path) configuration property has been deprecated and will be removed without a replacement.
